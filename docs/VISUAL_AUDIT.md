# Visual audit

The release evidence covers every manager-facing tab at desktop, mobile, and narrow-mobile widths, with diagnostic sections both collapsed and expanded where applicable. Automated browser checks record runtime exceptions, horizontal overflow, frame inventory, source coverage at release, page-source hash, live-manifest hash, and SHA-256 hashes for every screenshot. Publication-status notices are preserved as part of the interface and are not treated as software exceptions.

The standalone presentation contract uses a white research canvas, flat analytical surfaces, Arial throughout HTML and Plotly, tabular numerals, restrained navy, teal, brick, and amber semantic colors, standardized T, B, M, basis-point, percentile, and normalized-score formats, and a compact level-by-direction regime map. One coherent status rail communicates the index, direction, primary driver, funding state, and current market confirmation. Market confirmation and mechanical seasonality remain visually subordinate to the weighted Liquidity Conditions Index.

The current evidence set is stored under `docs/qa/liquidity_visual_audit_2026-09-06/product_v1`. It covers 21 viewport, tab, and disclosure-state combinations with no runtime exceptions or horizontal overflow.
