# Visual audit

The release evidence covers every manager-facing tab at desktop, mobile, and narrow-mobile widths, with diagnostic sections both collapsed and expanded where applicable. Automated browser checks record runtime exceptions, manager-facing data alerts, horizontal overflow, frame inventory, source coverage at release, page-source hash, live-manifest hash, and SHA-256 hashes for every screenshot. Data alerts are preserved as evidence and are not treated as software exceptions.

The presentation contract uses a white research-book canvas, black rules, Georgia display headings, Arial body and data text, square cards, restrained semantic color, standardized T, B, M, basis-point, percentile, and normalized-score formats, and a labeled level-by-direction regime matrix. Market confirmation and mechanical seasonality remain visually subordinate to the weighted liquidity index.
